# 静电场与轴频电场仿真数据结构与函数说明

> 适用对象：需要调用 `TargetElectricFieldModel` 生成水面舰船或潜艇电场数据的开发人员、测试人员和算法人员。

## 1. 功能概览

`TargetElectricFieldModel` 用来估算目标在海水中运动时，固定传感器位置能够测到的电场。模型会给出三类结果：

- **静电场**：主要表示船体腐蚀电流、涂层破损等因素形成的缓慢变化电场。
- **轴频电场**：主要表示螺旋桨轴旋转形成的周期性电场。
- **总电场**：静电场和轴频电场按三维方向相加后的结果。

最常用的调用过程是：

1. 创建并填写 `TargetParameter`。
2. 用参数创建 `TargetElectricFieldModel`。
3. 给出传感器的三维坐标。
4. 调用 `calculate()` 计算一个时刻，或调用 `simulate()` 连续计算一段时间。
5. 从 `ElectricFieldSignal` 中读取静电场、轴频电场和总电场。

## 2. 坐标、方向和单位

模型采用三维直角坐标系：

- `x`：向东为正。
- `y`：向北为正。
- `z`：向上为正，因此水面以下的位置通常填写负数。
- 航向角为 `0°` 时，目标沿 `x` 轴正方向运动。
- 航向角逆时针增加，例如 `90°` 表示沿 `y` 轴正方向运动。
- 俯仰角向上为正，向下航行时填写负数。

| 物理量 | 使用单位 |
|---|---|
| 长度、位置、距离 | 米（m） |
| 时间 | 秒（s） |
| 航速 | 米每秒（m/s） |
| 轴转速 | 转每分钟（r/min） |
| 频率 | 赫兹（Hz） |
| 电场强度 | 微伏每米（μV/m） |
| 海水电导率 | 西门子每米（S/m） |
| 温度 | 摄氏度（℃） |
| 压力 | 分巴（dbar） |

## 3. 数据结构

### 3.1 `TargetType`：目标类型

```cpp
enum class TargetType {
    SurfaceShip,
    Submarine
};
```

| 取值 | 通俗说明 |
|---|---|
| `TargetType::SurfaceShip` | 水面舰船 |
| `TargetType::Submarine` | 潜艇 |

目标类型会影响模型对浸水表面积和等效电极间距的自动估算。

### 3.2 `Vector3`：三维坐标或三维向量

```cpp
struct Vector3 {
    double x{0.0};
    double y{0.0};
    double z{0.0};
};
```

| 成员 | 类型 | 默认值 | 含义 |
|---|---|---:|---|
| `x` | `double` | `0.0` | `x` 方向的坐标或分量 |
| `y` | `double` | `0.0` | `y` 方向的坐标或分量 |
| `z` | `double` | `0.0` | `z` 方向的坐标或分量 |

`Vector3` 既能表示位置，也能表示电场向量。例如：

- `initialPosition` 表示位置，单位是 m。
- `totalFieldVector` 表示电场的三个方向分量，单位是 μV/m。

### 3.3 `TargetParameter`：仿真输入参数

这个结构保存一次仿真需要的全部输入条件，可以把它理解为目标的“参数卡”。

#### 3.3.1 目标类型和外形

| 成员 | 类型 | 默认值 | 单位 | 含义和要求 |
|---|---|---:|---|---|
| `type` | `TargetType` | `SurfaceShip` | 无 | 目标是水面舰船还是潜艇 |
| `tonnage` | `double` | `0.0` | t | 目标吨位，必须大于 0 |
| `length` | `double` | `0.0` | m | 目标长度，必须大于 0 |
| `width` | `double` | `0.0` | m | 目标宽度，必须大于 0 |
| `draft` | `double` | `0.0` | m | 吃水深度；潜艇可填写代表性的浸水高度，必须大于 0 |

这些参数用于描述目标外形，也会参与浸水表面积和静电场强度的自动估算。

#### 3.3.2 运动和姿态

| 成员 | 类型 | 默认值 | 单位 | 含义和要求 |
|---|---|---:|---|---|
| `velocity` | `double` | `0.0` | m/s | 目标航速，不能小于 0 |
| `shaftSpeed` | `double` | `0.0` | r/min | 螺旋桨轴转速，不能小于 0 |
| `initialPosition` | `Vector3` | `{0,0,0}` | m | `timeSeconds = 0` 时目标中心的位置 |
| `headingDegrees` | `double` | `0.0` | ° | 航向角；0° 沿 `x` 正方向，90° 沿 `y` 正方向 |
| `pitchDegrees` | `double` | `0.0` | ° | 俯仰角；向上为正，向下为负 |
| `shaftPhaseDegrees` | `double` | `0.0` | ° | 仿真开始时轴频波形的初始相位 |

当前模型按**匀速直线运动**计算目标位置，不模拟转弯、加速和减速。

轴频基波由轴转速换算得到：

```text
轴频（Hz）= 轴转速（r/min）÷ 60
```

例如轴转速为 120 r/min，轴频就是 2 Hz。

#### 3.3.3 海水环境

| 成员 | 类型 | 默认值 | 单位 | 含义和要求 |
|---|---|---:|---|---|
| `salinity` | `double` | `35.0` | 实用盐度 | 海水盐度，必须大于 0 且不超过 42 |
| `waterTemperature` | `double` | `15.0` | ℃ | 海水温度，允许范围为 -2～40 ℃ |
| `seaPressureDbar` | `double` | `0.0` | dbar | 海水压力，不能小于 0 |
| `conductivity` | `double` | `0.0` | S/m | 海水电导率；填 0 时自动估算，大于 0 时直接使用 |

如果已经测得现场海水电导率，建议直接填写 `conductivity`，通常比自动估算更可靠。

#### 3.3.4 静电场参数

| 成员 | 类型 | 默认值 | 单位 | 含义和要求 |
|---|---|---:|---|---|
| `staticDipoleMoment` | `double` | `0.0` | A·m | 静电场等效偶极矩；填 0 时自动估算，大于 0 时直接使用 |
| `corrosionCurrentDensity` | `double` | `1.0e-4` | A/m² | 船体等效腐蚀电流密度，不能小于 0 |
| `coatingDamageRatio` | `double` | `0.05` | 无 | 船体涂层破损比例，范围为 0～1；0.05 表示 5% |
| `electrodeSeparation` | `double` | `0.0` | m | 等效电极间距；填 0 时按照目标长度和类型自动估算 |

自动估算静电偶极矩时，大致采用下面的关系：

```text
静电偶极矩 ≈ 腐蚀电流密度
             × 浸水表面积
             × 涂层破损比例
             × 等效电极间距
```

如果掌握目标的实测静电偶极矩，直接填写 `staticDipoleMoment` 可以减少自动估算误差。

#### 3.3.5 轴频电场参数

| 成员 | 类型 | 默认值 | 单位 | 含义和要求 |
|---|---|---:|---|---|
| `shaftModulationRatio` | `double` | `0.04` | 无 | 轴频基波相对静电偶极矩的调制比例，不能小于 0 |
| `secondHarmonicRatio` | `double` | `0.20` | 无 | 二次谐波相对基波的比例，不能小于 0 |
| `thirdHarmonicRatio` | `double` | `0.05` | 无 | 三次谐波相对基波的比例，不能小于 0 |

如果基波频率为 2 Hz，那么二次谐波为 4 Hz，三次谐波为 6 Hz。

#### 3.3.6 最小计算距离

| 成员 | 类型 | 默认值 | 单位 | 含义和要求 |
|---|---|---:|---|---|
| `minimumDistance` | `double` | `1.0` | m | 传感器与目标中心允许的最小距离，必须大于 0 |

偶极子模型在距离非常小时会产生不合理的超大结果，因此用该参数阻止过近计算。

### 3.4 `ElectricFieldSignal`：一个时刻的输出结果

`calculate()` 返回一个 `ElectricFieldSignal`，`simulate()` 返回一组按时间排列的 `ElectricFieldSignal`。

| 成员 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `targetPosition` | `Vector3` | m | 当前时刻目标中心的位置 |
| `staticFieldVector` | `Vector3` | μV/m | 静电场在 `x`、`y`、`z` 三个方向上的分量 |
| `shaftFieldVector` | `Vector3` | μV/m | 当前时刻轴频电场的三个方向分量 |
| `totalFieldVector` | `Vector3` | μV/m | 总电场三个方向分量，等于静电场向量加轴频电场向量 |
| `staticField` | `double` | μV/m | 静电场向量的大小 |
| `shaftField` | `double` | μV/m | 当前时刻轴频电场向量的大小 |
| `shaftAmplitude` | `double` | μV/m | 当前目标位置对应的轴频基波幅值 |
| `totalField` | `double` | μV/m | 总电场向量的大小 |
| `frequency` | `double` | Hz | 轴频基波频率，即 `shaftSpeed / 60` |
| `distance` | `double` | m | 当前目标中心到传感器的直线距离 |
| `time` | `double` | s | 当前结果对应的仿真时间 |

需要特别注意：

- `staticField`、`shaftField` 和 `totalField` 表示向量的**大小**，通常是非负数。
- 前端要画带正负变化的波形时，应使用 `shaftFieldVector.x`、`shaftFieldVector.y` 或 `shaftFieldVector.z`。
- 做 FFT 频谱分析时，也应使用某个方向的电场分量，而不是只使用向量大小。
- `totalFieldVector = staticFieldVector + shaftFieldVector`。

## 4. 公开函数

公开函数是工程其他模块可以直接调用的接口。

### 4.1 默认构造函数

```cpp
TargetElectricFieldModel();
```

**作用：** 创建一个尚未设置目标参数的空模型。

**输入：** 无。

**输出：** 一个模型对象。

**注意：** 必须先调用 `setTarget()`，否则调用计算函数会抛出 `std::logic_error`。

### 4.2 带参数构造函数

```cpp
explicit TargetElectricFieldModel(const TargetParameter& param);
```

**作用：** 使用一组目标参数直接创建可计算的模型。

| 输入参数 | 类型 | 含义 |
|---|---|---|
| `param` | `const TargetParameter&` | 目标、运动、海水环境和电场源参数 |

**输出：** 一个已经完成参数设置的模型对象。

**异常：** 参数不合法时抛出 `std::invalid_argument`。

### 4.3 `setTarget()`：设置或更换目标

```cpp
void setTarget(const TargetParameter& param);
```

**作用：** 给空模型设置参数，或更换已有模型的目标参数。

| 输入参数 | 类型 | 含义 |
|---|---|---|
| `param` | `const TargetParameter&` | 新的目标参数 |

**输出：** 无返回值。参数有效时，模型内部保存新参数。

**异常：** 参数无效时抛出 `std::invalid_argument`，原来的有效参数不会被破坏。

### 4.4 `target()`：读取当前参数

```cpp
const TargetParameter& target() const;
```

**作用：** 查看模型当前正在使用的目标参数。

**输入：** 无。

**输出：** `TargetParameter` 的只读引用。可以读取，不能通过这个返回值直接修改模型参数。

**异常：** 模型还未设置参数时抛出 `std::logic_error`。

### 4.5 `calculate(sensorPosition, timeSeconds)`：计算一个时刻

```cpp
ElectricFieldSignal calculate(
    const Vector3& sensorPosition,
    double timeSeconds
) const;
```

**作用：** 计算指定时刻、指定传感器位置处的静电场、轴频电场和总电场。

| 输入参数 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `sensorPosition` | `const Vector3&` | m | 传感器在全局坐标系中的固定位置 |
| `timeSeconds` | `double` | s | 相对仿真起点的时间；0 表示初始时刻，也允许负数 |

**输出：** 一个 `ElectricFieldSignal`，包含目标位置、距离、轴频和三类电场结果。

**适合：** 查询某个确定时刻，或按自定义的不等间隔时间计算。

| 异常 | 常见原因 |
|---|---|
| `std::logic_error` | 模型还未设置目标 |
| `std::invalid_argument` | 传感器坐标或时间不是有效的有限数值 |
| `std::domain_error` | 目标到传感器的距离小于 `minimumDistance` |

### 4.6 `calculate(distance)`：按距离快速计算

```cpp
ElectricFieldSignal calculate(double distance) const;
```

**作用：** 简化计算。模型把传感器放在目标初始位置的 `x` 轴正方向，并在 `time = 0` 时计算。

```text
sensor.x = initialPosition.x + distance
sensor.y = initialPosition.y
sensor.z = initialPosition.z
```

| 输入参数 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `distance` | `double` | m | 传感器与目标初始中心在 `x` 方向的距离 |

**输出：** 一个 `ElectricFieldSignal`。

**适合：** 快速比较不同距离下的电场强弱。

**局限：** 只能计算初始时刻，而且传感器位置被限制在 `x` 轴方向。正式仿真建议使用上一种 `calculate()`。

**异常：** 模型未设置时抛出 `std::logic_error`；距离无效或小于最小距离时抛出 `std::invalid_argument`。

### 4.7 `simulate()`：连续仿真

```cpp
std::vector<ElectricFieldSignal> simulate(
    const Vector3& sensorPosition,
    double startTimeSeconds,
    double durationSeconds,
    double sampleRateHz
) const;
```

**作用：** 按固定采样率连续计算一段时间，用于生成时域曲线、目标经过传感器的过程曲线和频谱分析数据。

| 输入参数 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `sensorPosition` | `const Vector3&` | m | 固定传感器的位置 |
| `startTimeSeconds` | `double` | s | 仿真的开始时间 |
| `durationSeconds` | `double` | s | 仿真持续时间，必须大于或等于 0 |
| `sampleRateHz` | `double` | Hz | 每秒生成的采样点数，必须大于 0 |

**输出：** `std::vector<ElectricFieldSignal>`，结果按照时间从小到大排列。

采样点数为：

```text
采样点数 = floor(持续时间 × 采样率) + 1
```

例如持续 10 秒、采样率为 20 Hz，会得到 201 个点，其中包含开始时刻的点。

| 异常 | 常见原因 |
|---|---|
| `std::logic_error` | 模型还未设置目标 |
| `std::invalid_argument` | 时间或采样率无效，持续时间小于 0，或采样率小于等于 0 |
| `std::length_error` | 请求的采样点超过 1000 万个 |
| `std::domain_error` | 仿真过程中目标到传感器的距离小于 `minimumDistance` |

为了同时观察到三次谐波，采样率至少应满足：

```text
sampleRateHz > 2 × 3 × frequency
```

实际使用时建议再留出余量，一般可取最高关注频率的 5～10 倍。

## 5. 内部计算函数

下面的函数是私有函数，外部不能直接调用。公开接口会自动调用它们。

| 函数 | 作用 | 输入 | 输出 |
|---|---|---|---|
| `validateTarget(param)` | 检查目标参数是否合法 | `TargetParameter` | 无；不合法时抛出异常 |
| `ensureConfigured()` | 检查模型是否已经设置目标 | 无 | 无；未设置时抛出异常 |
| `calculateConductivity()` | 使用实测电导率，或根据盐度、温度和压力估算电导率 | 当前目标参数 | 电导率，S/m |
| `calculateWetArea()` | 根据类型、长度、宽度和吃水估算浸水表面积 | 当前目标参数 | 浸水表面积，m² |
| `calculateStaticDipoleMoment()` | 使用输入值，或根据腐蚀参数估算静电偶极矩 | 当前目标参数 | 偶极矩，A·m |
| `calculateTargetPosition(timeSeconds)` | 按初始位置、方向、速度和时间计算目标当前位置 | 时间，s | 目标中心坐标，m |
| `calculateTargetAxis()` | 把航向角和俯仰角转换成三维单位方向 | 当前姿态参数 | 三维单位向量 |
| `calculateDipoleField(relativePosition, dipoleMoment, conductivity)` | 使用电流偶极子近似计算电场 | 相对位置、偶极矩向量、电导率 | 三维电场向量，μV/m |
| `dot(lhs, rhs)` | 计算两个三维向量的点积 | 两个 `Vector3` | 标量 |
| `magnitude(value)` | 计算三维向量的长度 | 一个 `Vector3` | 向量大小 |
| `add(lhs, rhs)` | 两个三维向量相加 | 两个 `Vector3` | 相加后的向量 |
| `subtract(lhs, rhs)` | 两个三维向量相减 | 两个 `Vector3` | 相减后的向量 |
| `scale(value, factor)` | 三维向量乘以系数 | `Vector3` 和系数 | 缩放后的向量 |

## 6. 最小调用示例

```cpp
#include "TargetElectricFieldModel.h"

#include <iostream>

int main() {
    // 填写目标外形、运动状态和海水环境。
    TargetElectricFieldModel::TargetParameter parameter;
    parameter.type = TargetElectricFieldModel::TargetType::SurfaceShip;
    parameter.tonnage = 5000.0;
    parameter.length = 120.0;
    parameter.width = 18.0;
    parameter.draft = 6.0;
    parameter.velocity = 8.0;
    parameter.shaftSpeed = 120.0;
    parameter.salinity = 35.0;
    parameter.waterTemperature = 15.0;
    parameter.initialPosition = {-300.0, 0.0, -3.0};
    parameter.headingDegrees = 0.0;

    // 使用参数创建可计算的电场模型。
    TargetElectricFieldModel model(parameter);

    // 传感器位于水下 20 米处。
    const TargetElectricFieldModel::Vector3 sensorPosition{
        0.0,
        100.0,
        -20.0
    };

    // 计算第 10 秒时的单点结果。
    const auto onePoint = model.calculate(sensorPosition, 10.0);
    std::cout << "总电场: " << onePoint.totalField << " uV/m\n";

    // 连续仿真 60 秒，采样率为 20 Hz。
    const auto signals = model.simulate(
        sensorPosition,
        0.0,
        60.0,
        20.0
    );

    // 读取时间和三轴总电场，可用于前端绘图。
    for (const auto& signal : signals) {
        std::cout
            << signal.time << ","
            << signal.totalFieldVector.x << ","
            << signal.totalFieldVector.y << ","
            << signal.totalFieldVector.z << "\n";
    }

    return 0;
}
```

## 7. 怎样把结果交给前端

连续仿真时，后端可以把 `simulate()` 返回的每个采样点转换成 JSON。建议至少传递：

- `time`
- `targetPosition`
- `distance`
- `frequency`
- `staticFieldVector`
- `shaftFieldVector`
- `totalFieldVector`
- `staticField`
- `shaftField`
- `shaftAmplitude`
- `totalField`

绘图字段建议如下：

| 图表 | 横轴 | 纵轴 |
|---|---|---|
| 总电场时域曲线 | `time` | `totalField` |
| 三轴总电场曲线 | `time` | `totalFieldVector.x/y/z` |
| 带正负变化的轴频波形 | `time` | `shaftFieldVector.x/y/z` |
| 目标距离曲线 | `time` | `distance` |
| 目标运动轨迹 | `targetPosition.x/y/z` | 三维轨迹 |
| 轴频频谱 | 对某个轴频电场分量做 FFT | 频率和频谱幅值 |

## 8. 常见问题

### 8.1 生成一段电场曲线，调用哪个函数？

调用 `simulate(sensorPosition, startTimeSeconds, durationSeconds, sampleRateHz)`。

### 8.2 只计算某一时刻，调用哪个函数？

调用 `calculate(sensorPosition, timeSeconds)`。

### 8.3 已经测得海水电导率，填哪个参数？

填写 `conductivity`。只要它大于 0，模型就直接使用该值。

### 8.4 已经知道目标静电偶极矩，填哪个参数？

填写 `staticDipoleMoment`。只要它大于 0，就不会再根据腐蚀参数自动估算。

### 8.5 为什么计算时报“距离太近”？

当前目标中心到传感器的距离小于 `minimumDistance`。应调整目标航迹、传感器位置或合理设置最小计算距离。

### 8.6 仿真结果能否直接代表真实舰船？

这套模型适合软件联调、趋势分析、参数敏感性分析和合成数据生成。真实目标还会受到船体材料、阴极保护系统、涂层实际状态、螺旋桨结构、海床边界和海水分层等因素影响。

工程应用时，建议优先使用实测或标定得到的海水电导率、静电偶极矩、轴频调制比例和谐波比例。
